# Запомнить

Облачный контейнер одноразовый: всё, что не попало в репозиторий, пропадает вместе с сессией. Постоянная память проекта — файл `.claude/memory/MEMORY.md`. Он подключён в `.claude/CLAUDE.md` и загружается в начале каждой сессии.

## Порядок

1. Прочитай `.claude/memory/MEMORY.md`. Если похожая запись уже есть — обнови её; если новая противоречит старой — замени старую, а не добавляй вторую рядом.
2. Запиши в подходящий раздел (нет подходящего — создай) одной строкой: `- ГГГГ-ММ-ДД — суть`. Факт и, если неочевидно, причина. Без воды.
3. Закоммить отдельным коммитом `chore(memory): …` и запушь вместе с текущей работой. Ответь пользователю одной строкой, что запомнил.
4. Новые сессии стартуют с `main`, поэтому запись заработает после слияния PR в `main` — напомни об этом, если PR ещё не слит.

## Что куда

- Постоянное правило работы («всегда делай X») → раздел «Правила» в `.claude/CLAUDE.md`.
- Факты, решения, договорённости, предпочтения → `.claude/memory/MEMORY.md`.
- Нельзя сохранять: пароли, токены, ключи API, чужие персональные данные. Репозиторий видят все, у кого есть к нему доступ. Секреты хранятся в переменных окружения облачной среды.
- Журнал длиннее ~150 строк — сожми: объедини похожие записи, удали устаревшие.

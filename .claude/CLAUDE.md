# «Вкусная компания» — сайт ресторана

Сайт ресторана в Самаре на Nuxt 3 + Tailwind CSS. Анимации — GSAP (ScrollTrigger), плавный скролл — Lenis, разбивка текста на буквы — SplitType. Тексты сайта — на русском.

## Команды

- `npm ci` — установить зависимости (в новой облачной сессии их нет)
- `npm run dev` — dev-сервер на http://localhost:3000
- `npm run build` — продакшен-сборка; `npm run generate` — статическая генерация
- `npm run optimize:images` — создаёт `.avif`/`.webp` рядом с `.jpg`/`.png` в `public/images`, `public/content`, `public/img` (готовые не перезаписывает)

## Устройство

- Бренд (название, цвета, шрифты) — `brand.config.ts`; CSS-переменные цветов — `assets/css/main.css`, палитра `primary` — `tailwind.config.js`.
- Страницы — `pages/` (index, menu, about, contact). Общий макет `layouts/default.vue`: навигация, футер, JSON-LD организации и глобальная модалка бронирования.
- Модалка бронирования — `components/ReservationModal.vue`; открывается общим флагом из `composables/useReservationModal.ts`.
- GSAP, Lenis и SplitType работают только в браузере (`plugins/*.client.ts`), у директивы `v-split` есть SSR-заглушка `plugins/split-type.server.ts`. Не импортируй эти библиотеки в код, который выполняется на сервере.
- Адрес и телефон продублированы в нескольких местах: `components/AppFooter.vue`, `pages/contact.vue` (вместе с JSON-LD и meta), `pages/index.vue`, `pages/about.vue`. Меняешь — найди все вхождения поиском.

## Правила

- Коммиты — Conventional Commits (`feat:`, `fix:`, `chore(...):`), история релизов — `CHANGELOG.md`.
- Тестов и линтера нет: после правок кода проверяй, что проходит `npm run build`.

## Работа в облаке

- Сессия идёт в одноразовом облачном контейнере: репозиторий клонируется заново при старте, а всё, что не закоммичено и не запушено, пропадает. Домашняя папка `~/.claude` контейнера тоже одноразовая, поэтому память, скиллы и файлы храним здесь, в `.claude/` репозитория.
- Новая сессия по умолчанию стартует с `main`: правки памяти, скиллов и этого файла начинают действовать после слияния PR в `main`.
- Секреты (пароли, токены, ключи API) — никогда не в репозиторий и не в чат: только переменные окружения в настройках облачной среды.

## Папка `.claude/`

- `CLAUDE.md` — этот файл: знания о проекте и правила работы. Читается автоматически в начале каждой сессии.
- `memory/MEMORY.md` — журнал памяти: факты, решения, предпочтения. Подключён ниже, пополняется скиллом `project-memory` («запомни»).
- `skills/<имя>/SKILL.md` — скиллы проекта. Новый скилл — новая папка с `SKILL.md`.
- `files/` — рабочие файлы, которые не входят в сайт (тексты, меню, документы). Картинки для сайта — в `public/`.

# Рабочие файлы

Сюда кладём файлы, которые нужны в работе, но не являются частью сайта: тексты, меню, прайсы, документы, черновики. Всё, что лежит здесь и попало в `main`, доступно в любой новой облачной сессии.

- Картинки для сайта — не сюда, а в `public/` (после добавления запусти `npm run optimize:images`).
- Секреты (пароли, токены, ключи) — никогда не в репозиторий.
- GitHub не принимает файлы больше 100 МБ; большие файлы лучше держать в Google Drive.
